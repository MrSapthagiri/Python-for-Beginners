# Module 8: Lists

Lists let a Python program keep multiple values together in one ordered,
changeable collection. In this module, each topic has its own Python file with
definitions, explanations, runnable examples, and expected output in comments.

## Topics and files

1. **List creation, indexing, slicing, and updating**
   - File: `01_list_creation_indexing_slicing_updating.py`
   - Create a list, access values by index, select a range with slicing, and
     replace values.
2. **Adding and removing elements**
   - File: `02_adding_removing_elements.py`
   - Use `append()`, `insert()`, `remove()`, and `pop()`.
3. **Common list methods**
   - File: `03_list_methods.py`
   - Sort and reverse a list, find an item's index, and count occurrences.
4. **Nested lists and iteration**
   - File: `04_nested_lists_and_iteration.py`
   - Store lists inside lists and visit their items with loops.
5. **List comprehensions and basic problem solving**
   - File: `05_list_comprehensions_and_problems.py`
   - Build lists from iterables and solve small filtering and transformation
     problems.

## Running the examples

Open a `.py` file and run it with Python. For example:

```bash
python 01_list_creation_indexing_slicing_updating.py
```

Each file prints sample results. The comments beside each example explain the
code and show the expected output.
