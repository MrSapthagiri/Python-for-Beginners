# Module 9: Tuple, Set & Dictionary

This module introduces three built-in Python collection types. Each topic has
its own Python file with definitions, explanations, runnable examples, and
expected output in comments.

## Topics and files

1. **Tuples: creation, indexing, slicing, methods, and tuple vs. list**
   - File: `01_tuples.py`
   - Create immutable tuples, read their items, use common tuple methods, and
     compare tuples with mutable lists.
2. **Sets: creation, uniqueness, adding/removing, and operations**
   - File: `02_sets.py`
   - Create sets, add and remove values, and use union, intersection, and
     difference.
3. **Dictionaries: key-value pairs and basic operations**
   - File: `03_dictionaries.py`
   - Create dictionaries, access values by key, update entries, and delete
     entries.
4. **Dictionary methods**
   - File: `04_dictionary_methods.py`
   - Use `keys()`, `values()`, `items()`, and `get()`.

## Running the examples

Open a `.py` file and run it with Python. For example:

```bash
python 01_tuples.py
```

Each file prints sample results. The comments beside each example explain the
code and show the expected output.
